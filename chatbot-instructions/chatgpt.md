# Using Prism with ChatGPT

1. Start a new chat.
2. Paste one prompt from [`../prompts/`](../prompts/).
3. Paste your artifact.
4. Ask ChatGPT to follow every step and cite evidence.

Recommended opener:

```text
Use this Prism method as your analysis protocol. Do not summarize the protocol. Apply it to the artifact below and produce the required outputs.
```

For long documents, upload the file and paste the Prism prompt as the instruction.
